# schemas

JSON schemas for Nowable Pi.

## Contenido

- `nowable-publication-metadata.schema.json` — canonical contract for Nowable landing publication metadata, Cloudflare URLs, version ordering, TTL, state, approval, and retrieval policy.
- `worker-contract.schema.json` — closed contract for `nowable.worker` execution.
- `worker-handoff.schema.json` — worker completion handoff contract.
- `verifier-report.schema.json` — independent verification report contract.
