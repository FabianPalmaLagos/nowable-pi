# harness

Infraestructura operativa local para Nowable Pi.

## Contenido

- `policies/` — reglas de seguridad, bash, domain lock, verificación y OpenSpec.
- `schemas/` — contratos JSON para metadata de publicación y handoffs ADW.
- `templates/` — plantillas Markdown/YAML para operadores y agentes.
- `fixtures/` — registros determinísticos de prueba.
- `mental-models/` — memoria estable por rol.
- `runs/` — artefactos por corrida.
- `evals/` — checks determinísticos locales.
- `reports/` — reportes locales de ejecución y verificación.
